# Персональний веб-сайт на Flask + HTML + CSS

Сучасний, швидкий та адаптивний персональний сайт-портфоліо, розроблений за допомогою Python (Flask), семантичного HTML5 та чистого CSS3.

## 🚀 Функціонал

- **Головна сторінка (`/`)**: презентація розробника, статус доступності, інтерактивна картка з кодом, ключові проєкти та навички.
- **Про мене (`/about`)**: розширена інформація, філософія розробки, стек технологій та контакти.
- **Проєкти (`/projects`)**: каталог робіт із тегами технологій та посиланнями на вихідний код.
- **Контакти (`/contact`)**: форма зворотного зв'язку з валідацією та Flash-сповіщеннями, посилання на соцмережі.
- **Сторінка 404**: кастомна сторінка для неіснуючих маршрутів.
- **Адаптивний дизайн**: коректне відображення на мобільних телефонах, планшетах та десктопах.

## 📁 Структура проєкту

```text

│   ├── projects.html      # Сторінка "Проєкти"
│   ├── contact.html       # Сторінка контактів

    └── js/
        └── main.js        # Скрипти (меню, дата, повідомлення)
```

## 🛠 Встановлення та запуск

### 1. Клонування або перехід у папку проєкту
```bash
cd olegnovosad.github.com
```

### 2. Створення та активація віртуального середовища
```bash
# macOS / Linux
python3 -m venv .venv
source .venv/bin/activate

# Windows
python -m venv .venv
.venv\Scripts\activate
```

### 3. Встановлення залежностей
```bash
pip install -r requirements.txt
```

### 4. Запуск сервера розробки
```bash
python app.py
```

Після запуску відкрийте браузер за адресою:
👉 **[http://127.0.0.1:5000](http://127.0.0.1:5000)**

## ⚙️ Налаштування персональних даних

Усі дані (ім'я, посилання, опис, список навичок та проєктів) знаходяться на початку файлу `app.py`:
- `PROFILE` — контактні дані, ім'я, локація, соціальні мережі.
- `SKILLS` — категорії технологій та інструментів.
- `PROJECTS` — список проєктів з описом, тегами та посиланнями.

Ви можете просто змінити значення цих змінних під свої потреби без зміни HTML-структури.
